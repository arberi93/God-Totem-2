# God Totem

A Fabric mod for Minecraft 26.2 that adds the **God Totem**, a stronger Totem of Undying.

- Works from the main hand or off hand
- Saves you from death, clears bad effects and fully heals you
- Two uses before it breaks
- Effects on use:
  - Absorption V (+10 hearts) for 3 minutes
  - Regeneration X for 5 seconds, then Regeneration III for 45 seconds
  - Strength II for 3 minutes
  - Speed III for 1 minute
  - Fire Resistance II for 40 seconds

## Recipe

```
Gold Block | Netherite Ingot | Gold Block
Diamond    | Totem of Undying | Redstone
Gold Block | Lapis Block      | Gold Block
```

## Building without installing anything

1. Make a free GitHub account and create a new repository.
2. Upload all of these files and folders (including the hidden `.github` folder).
3. Open the **Actions** tab, wait for "Build mod" to finish, then download `god-totem-jar` from the run page.
4. Unzip it and put the `.jar` in your `.minecraft/mods` folder together with Fabric API.

The texture at `src/main/resources/assets/godtotem/textures/item/god_totem.png` is a placeholder. Replace it with your own 16x16 PNG with the same name.
